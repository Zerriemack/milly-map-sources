# Milly Map Sources

This site is my sources roadmap for studying DraftKings NFL GPP contests with a focus on Milly Maker style fields. My goal is simple. Build repeatable decision rules for roster construction, then test those rules against results, tools, and research.

I grouped sources into categories so I can find what I need fast during a slate build.

## Categories

1. [Rules and Scoring](rules/index.md)  
2. [Historical Winners and Contest Links](winners/index.md)  
3. [Tools and Simulation](tools/index.md)  
4. [Data and Stats Reference](data/index.md)  
5. [Academic Research](research/index.md)  
6. [Media and Practical Film Room Style Analysis](media/index.md)

## How I use these sources

I start with rules and scoring so every assumption matches DraftKings constraints. I use winner pages to study what actually happened. I use tools to simulate and stress test builds. I use data sites to support projections and role clarity. I use research papers to borrow formal language and modeling ideas. I use media sources for matchup context and angle finding.

## Notes on my approach

My edge comes from committing to a small set of core outcomes on a slate and building lineups around those convictions, instead of spreading exposure across every reasonable play.
