# Pro Football Reference

Link: [Pro Football Reference](https://www.pro-football-reference.com/)

Discovery method: Known stats reference site used for historical validation.

Annotation:  
Summary: Pro Football Reference provides historical player, team, and game level stats in a format built for research and validation.  

Credibility: It is a long running sports reference platform used widely for statistics lookup.  

Use in my project: I use it to validate trends behind winning builds, such as team pace, scoring environment, target distribution, and touchdown concentration. It helps me check assumptions fast without relying on subjective narratives.  

Limitations: It focuses on recorded stats, so it does not capture full context such as play design intent or injury limitations.
