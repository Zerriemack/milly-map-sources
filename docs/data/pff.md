# Pro Football Focus

Link: https://www.pff.com/

Discovery method: Industry standard football analytics source used in DFS research.

Annotation:  
Summary: PFF provides grades, matchup context, and usage information that can explain performance beyond box scores.  
Credibility: It is a major football analytics publisher with consistent processes and wide adoption across football media and analysis.  
Use in my project: I use PFF to justify player roles, line play edges, coverage matchups, and usage trends that shape ceiling outcomes. This supports decisions on who is truly in a strong position to break a slate.  
Limitations: Many features sit behind a paywall, and grades are still a model with judgment baked in.
