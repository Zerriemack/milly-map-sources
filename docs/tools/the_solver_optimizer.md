# The Solver NFL Optimizer

Link: [The Solver](https://thesolver.com/)

Discovery method: Specialized optimizer tool research.

Annotation:  
Summary: The Solver is an optimizer that supports building lineups with constraints such as stacking rules, correlation rules, and exposure control.  

Credibility: It is a dedicated DFS optimizer product used for multi entry portfolio building.  

Use in my project: I use it to convert strategy into repeatable lineup rules instead of hand building. It helps me enforce my core slate positions by locking players, controlling exposures, and building correlated lineups at scale.  

Limitations: It does not create edge by itself. The edge depends on constraints, player selection, and the assumptions behind projections.
