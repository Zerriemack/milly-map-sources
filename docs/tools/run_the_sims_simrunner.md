# Run The Sims NFL SimRunner

Link: https://www.runthesims.com/

Discovery method: Specialized DFS tool discovery through community discussion and tool research.

Annotation:  
Summary: Run The Sims provides slate simulations so users can compare outcomes across builds using simulated game ranges.  
Credibility: It is a well known DFS simulation product used by serious players, built around repeatable simulation methods rather than takes.  
Use in my project: I use it to compare lineup constructions, ownership leverage, and stack structures, then see which archetypes show higher top end outcomes. It supports Classic Milly decisions around correlation and lineup uniqueness.  
Limitations: Inputs and assumptions drive outputs, so results depend on projection quality and the simulation model.
