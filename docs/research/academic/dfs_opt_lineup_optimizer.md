# DFL-Opt: A Daily Fantasy Lineup Optimizer

Link: [Digital Commons (Montclair State) landing page](https://digitalcommons.montclair.edu/etd/677/)

This master’s project presents DFL-Opt, a daily fantasy lineup optimizer built around linear programming. It treats lineup building as a constrained selection problem, then explains how an optimizer can handle salary caps, roster slots, and site rules while generating lineups automatically. The author also includes a small real contest test in DraftKings Showdown Captain Mode contests from late February to early March 2020, using results to reflect on performance and next steps.

This source is valuable because it connects DFS lineup building to formal optimization logic in plain terms, which supports a more testable process than “feel” picks. DFS players who want repeatable lineup generation, plus students learning optimization through a real sports use case, would benefit most.

Limitations include the narrow testing window and reliance on the inputs available at the time. The optimizer’s output quality still depends on projections and assumptions, so results need ongoing validation.
