# DraftKings NFL Scoring Rules

Link: [DraftKings NFL Scoring Rules](https://help.draftkings.com/hc/en-us/articles/4405231687571-NFL-Scoring)


Discovery method: Direct lookup on the DraftKings help center.

Annotation:  
Summary: This page lists scoring events for NFL contests and how points are awarded.  

Credibility: Official DraftKings scoring is the scoring system, so it is the baseline source.  

Use in my project: I tie lineup construction rules to scoring incentives, for example how bonuses and touchdown scoring change stacking, ceiling chasing, and position value. It also supports my writeups when I explain why certain archetypes show up in winning lineups.  

Limitations: It does not address ownership, contest selection, or multi entry portfolio decisions.
